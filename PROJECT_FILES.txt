CÓDIGO FONTE - MODEL (Modelo)
------------------------------
- src/main/java/br/ita/mvc/model/Dictionary.java
  * Classe que gerencia o dicionário de traduções
  * Carrega traduções do arquivo properties
  * Método translate() para buscar traduções

CÓDIGO FONTE - CONTROLLER (Controlador)
----------------------------------------
- src/main/java/br/ita/mvc/controller/TranslateServlet.java
  * Servlet mapeado para /translate
  * Recebe requisições HTTP POST
  * Coordena Model e View

CÓDIGO FONTE - VIEW (Visão)
----------------------------
- src/main/webapp/index.jsp
  * Página principal com formulário de entrada
  * Campo de texto para a palavra
  * Botão "Traduzir"

- src/main/webapp/WEB-INF/result.jsp
  * Página de resultado
  * Exibe palavra original e tradução
  * Botão para nova tradução

CONFIGURAÇÃO WEB
----------------
- src/main/webapp/WEB-INF/web.xml
  * Configuração do servlet container
  * Define welcome file (index.jsp)
  * Filtro de encoding UTF-8

DADOS
-----
- src/main/resources/dictionary.properties
  * Arquivo com 25 pares palavra+tradução
  * Formato: palavra_inglesa=tradução_portuguesa

TESTES
------
- src/test/java/br/ita/mvc/test/TranslatorSeleniumTest.java
  * 3 testes funcionais com Selenium
  * Teste 1: palavra "hello" (existe)
  * Teste 2: palavra "computer" (existe)
  * Teste 3: palavra "programming" (não existe)

ARQUIVO GERADO (após mvn package)
----------------------------------
- target/translator-webapp.war
  * Arquivo WAR para deploy no Tomcat
  * Contém toda a aplicação compilada

COMANDOS ÚTEIS
--------------
Compilar:          mvn clean compile
Gerar WAR:         mvn clean package
Executar testes:   mvn test
Limpar build:      mvn clean

REQUISITOS ATENDIDOS
--------------------
✓ Aplicação web com campo texto e botão "Traduzir"
✓ Processamento no servidor com Servlet
✓ Retorno com página de resultado
✓ Arquivo com traduções (25 pares)
✓ Retorna palavra original se não encontrar tradução
✓ Divisão em camadas MVC
✓ Uso de classes Java, Servlets e JSP
✓ Sem frameworks adicionais
✓ 3 testes funcionais com Selenium
✓ Projeto Maven (compatível Eclipse/NetBeans)
✓ Documentação completa
